# Wee Greens — cottage-ink working draft

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8000
```

Then visit http://127.0.0.1:8000/

Art direction: cottage ink (cream paper, botanical plates, serif + handwriting). Logo: `assets/logo.svg` (seal with pea shoot + WEE GREENS). Geography: Edinburgh. Draft only — form does not send until an email is set in `assets/script.js`.
